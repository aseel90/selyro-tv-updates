# Selyro TV — Public Updates

Public distribution files for the **Selyro TV** Android TV app.

- `latest.json` is the update manifest consumed by the app.
- `Selyro-TV-latest.apk` is the downloadable, signed Android application package.
- `Selyro-TV-latest.sha256` provides the SHA-256 checksum of the APK.

Application source code and private provider information are **not** published here.

**Security notice:** The current Android installer APK is signed with the pre-existing Android test key for compatibility with existing installations. This is a temporary development release signer, not a production-grade identity. Do not use this update channel to distribute an app outside the existing test environment.
